
# Lab 2 - Interactive Portfolio Enhancements

## Project description

This project builds on my portfolio from Lab 1. For Lab 2, I am adding an interactive feedback form using HTML, CSS and vanilla JavaScript.

## Target grade

Grade 3

## Features

- Feedback form with full name, email, topic, comments and optional website URL.
- Form validation with clear error messages.
- Live character counter for the comments field.
- Success message after valid submission.
- Clear button to reset the form.
- Responsive layout for different screen sizes.

## Technologies

- HTML
- CSS
- JavaScript (vanilla)
- Git and GitHub

## How to run

1. Download or clone this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
